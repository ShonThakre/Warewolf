# Werewolf UX mockups

Twelve 1586×992 reference screens, regenerated in the application’s deep-plum, violet, and gold palette, with **screen-by-screen Cursor prompts**.

Use `SCREEN-PROMPTS.md` one prompt at a time. Each prompt contains measured layout anchors, the existing art mappings, app-theme colors, implementation constraints, and a production QA workflow using the repo’s Playwright setup. The mockups are achievable visual targets; current routes, data, permissions, and server rules remain authoritative. Portrait assets use the `*-phone.png` suffix. The shared phone design system and one-screen-at-a-time Cursor prompts are in `PHONE-IMPLEMENTATION-PLAN.md`.
